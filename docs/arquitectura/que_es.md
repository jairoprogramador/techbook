# ¿Qué es la Arquitectura de Software?
La industria de software no se ha puesto de acuerdo respecto ha esta pregunta, hay muchas definiciones, pero hay conceptos que se repiten que lo podemos sintetizar de esta manera:

La arquitectura de software es el diseño de mas alto nivel de la estructura de un sistema, el cual consiste en un conjunto de patrones y abstractiones que proporcionan un marco claro para implementar y mantener un sistema.
