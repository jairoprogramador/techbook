# Azure Monitor

## Analogía

Azure Monitor es como el sistema nervioso central de tu infraestructura en la nube. Imagina que tienes un edificio enorme con cientos de sistemas: aire acondicionado, electricidad, seguridad, ascensores, etc. En lugar de tener un monitor separado para cada sistema en diferentes lugares, tienes un centro de control central donde llega toda la información. Este centro recibe datos de todos los sistemas, los organiza, los analiza y te muestra tableros con el estado de todo. Si algo falla, te alerta inmediatamente. Si necesitas un reporte de salud, lo genera automáticamente. No es un sistema aislado, es la plataforma completa que conecta todo y te da visibilidad total de lo que está pasando en tu infraestructura.

## Definición

Azure Monitor es la plataforma central de monitoreo de Azure que recolecta métricas y registros de casi todos los recursos de Azure para centralizar la visibilidad y proporcionar insights operativos.

Permite:

- Recolectar métricas y registros de recursos de Azure de forma centralizada
- Centralizar la visibilidad de toda la infraestructura en un solo lugar
- Alimentar alertas automáticas basadas en condiciones configuradas
- Generar tableros personalizados con visualizaciones de datos
- Producir reportes de salud y análisis de rendimiento
- Integrar con servicios de Azure y recursos externos

## Componentes

**Métricas** – Datos numéricos que describen el rendimiento y el estado de los recursos en tiempo real

**Registros (Logs)** – Datos de eventos y actividades que se almacenan para análisis y consulta

**Alertas** – Notificaciones automáticas basadas en métricas o registros que cumplen condiciones específicas

**Tableros (Dashboards)** – Visualizaciones personalizadas que muestran métricas y datos de múltiples recursos

**Workbooks** – Reportes interactivos que combinan datos de múltiples fuentes para análisis

**Application Insights** – Servicio integrado para monitoreo de aplicaciones y rendimiento

**Log Analytics** – Servicio para consultar y analizar registros de múltiples fuentes

## Funcionalidad

1. Azure Monitor recolecta automáticamente métricas y registros de recursos de Azure
2. Los datos se almacenan en un repositorio centralizado accesible desde múltiples servicios
3. Se configuran alertas que evalúan métricas o registros contra condiciones definidas
4. Cuando se cumple una condición, se dispara una alerta con notificaciones configuradas
5. Los tableros se alimentan de los datos recolectados para mostrar visualizaciones en tiempo real
6. Los reportes de salud se generan analizando métricas y registros para identificar problemas
7. La plataforma integra datos de múltiples fuentes para proporcionar visibilidad completa

## Casos de Uso

- Monitorear el rendimiento y disponibilidad de máquinas virtuales y aplicaciones
- Detectar problemas y fallos mediante alertas automáticas
- Analizar tendencias de uso y rendimiento a lo largo del tiempo
- Generar reportes de salud para auditorías y cumplimiento
- Visualizar métricas clave en tableros personalizados para equipos
- Investigar incidentes consultando registros históricos de eventos
- Optimizar recursos basándose en datos de uso y rendimiento
