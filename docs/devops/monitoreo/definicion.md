# Definición

El monitoreo responde: **¿Está funcionando mi sistema?**

El monitoreo consiste en recopilar métricas y verificar si el sistema cumple determinadas condiciones predefinidas.

Por ejemplo, puedes monitorear:

- Uso de CPU.
- Memoria RAM.
- Espacio en disco.
- Cantidad de peticiones por segundo.
- Tiempo de respuesta promedio.
- Estado de un endpoint /health.

Si alguna métrica supera un umbral, se genera una alerta. El monitoreo es muy útil para detectar que existe un problema.
